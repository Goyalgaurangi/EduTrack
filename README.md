# EduTrack

Attendance, grades and records, in real time.

EduTrack is a demo academic portal for faculty, students, and administrators. It starts with sample CSE-A data so the attendance, grading, report-card, and at-risk student flows are ready to demonstrate.

## Run

Use the Replit **Run** button to start the web app and its API. The academic demo records are created automatically the first time the API starts with an empty database. Existing records are kept on later starts.

The role switcher is a demo control, not account authentication or access control.

## 60-second demo

1. Switch to **Faculty**, open **Attendance**, choose a course and date, mark one student absent, and save. The confirmation appears immediately.
2. Open **Grades**, choose a course and exam, change a mark, and save.
3. Switch to **Student**, select a student, and review attendance, marks, the low-attendance recovery estimate, and the quote card.
4. Open that student's report card and choose **Print / Save as PDF**.
5. Switch to **Admin** to review the attendance summary, at-risk students, and grade distribution. Add a student to see the directory update.
